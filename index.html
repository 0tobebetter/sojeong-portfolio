Context배경

Joined as the first dedicated Data Analyst in the marketing team. Data was locked behind a legacy admin system — extracting a single dataset took 3–4 hours, and the underlying database had an undocumented bug causing truncated exports (1,000 rows requested → ~960 returned). Engineering support required 3 days to 2 weeks per request.마케팅팀 최초 데이터 애널리스트로 합류. 데이터는 레거시 관리자 시스템에 묶여 있었고, 단일 데이터셋 추출에 3~4시간 소요. 데이터베이스에는 미문서화 버그(1,000행 요청 → 약 960행 출력)가 있었고, 개발팀 지원 요청 시 3일~2주가 걸렸음.

What I built구축 내용

Automated bulk extraction of 4 years of customer data using Python, merged sources into a unified 70k+ record database in Google Sheets, and built filter/arrayformula-based self-serve query sheets. Integrated Google, Meta, and Naver ad performance into a single monthly dashboard with one-click month switching via Apps Script. Connected government API (KDT/KDC) for daily auto-updating market intelligence, replacing quarterly manual reporting.Python으로 4년치 고객 데이터 자동 추출, 70k+ 레코드 통합 DB 구축. The most impactful data work is often removing the friction that prevents data from being used at all. Accessibility beats sophistication.가장 임팩트 있는 데이터 작업은 데이터가 아예 쓰이지 못하게 하는 마찰을 없애는 것. 접근성이 정교함보다 중요하다.

Context배경

Designed and owned end-to-end analytics across 4 recruitment campaigns (~900 total applicants) for government-backed education programmes. Built intake dashboards, channel-level funnel analysis, and a conversion heatmap table used across marketing and operations teams.정부 지원 교육 프로그램 4개 모집 캠페인(총 약 900명) 전반의 애널리틱스 설계·운영. 유입 대시보드, 채널별 퍼널 분석, 마케팅·운영팀 공용 전환 히트맵 테이블 구축.

Key finding핵심 인사이트

Initial targeting focused on early-20s users (AI tools for university assignments). Heatmap analysis revealed that 40–50s age groups were converting at significantly higher rates. Marketing strategy was overhauled to target this segment. Separately, the heatmap identified a bottleneck in the sales follow-up stage.초기 타겟은 20대 초반. 히트맵 분석 결과 40~50대의 전환율이 현저히 높음을 발견. 신청 폼에 AI 활용도 5점 척도를 추가해 검증 — 40~50대가 주요 전환 세그먼트임을 확인, 마케팅 전략 전면 수정. 영업 팔로업 단계의 병목도 히트맵으로 식별.

Key insight핵심 교훈

Assumed audience and actual converting audience can be entirely different. The data didn't just confirm a hypothesis — it replaced one.가정한 오디언스와 실제 전환 오디언스는 전혀 다를 수 있다. 데이터는 가설을 검증하는 데 그치지 않고, 가설 자체를 대체했다.

Context배경

Independently planned, built, and deployed a Korean-language quiz web app as a self-directed GA4/GTM portfolio project. Designed the full analytics stack from scratch — GTM container, GDPR-compliant cookie consent (Consent Mode v2), custom event tracking, and custom dimensions. Drove organic traffic via community referrals and analysed behaviour in GA4 Explore.GA4/GTM 포트폴리오 프로젝트로 한국어 퀴즈 웹앱을 직접 기획·개발·배포. GTM 컨테이너, GDPR 준수 쿠키 동의(Consent Mode v2), 커스텀 이벤트·디멘션까지 애널리틱스 스택 전체를 처음부터 설계. 커뮤니티 레퍼럴로 유입된 트래픽을 GA4 Explore에서 분석.

Key finding핵심 인사이트

Quiz start→complete rate held at 81% (74→60), but result sharing dropped to 17% (10/60). With 89% mobile users, friction in the share flow was the primary drop-off point — identified as the next optimisation target.퀴즈 시작→완료율은 81%(74→60)로 양호했으나, 결과 공유율은 17%(10/60)에 그침. 89% 모바일 사용자 기준 공유 플로우의 UX 마찰이 주요 이탈 원인으로 분석.

Lesson learned배운 점

GA4 Custom Dimensions must be registered before launch — retroactive setup causes data gaps. Now use a pre-launch analytics checklist on every project.GA4 커스텀 디멘션은 런칭 전 등록 필수. 사후 세팅 시 데이터 공백 발생. 이후 모든 프로젝트에 사전 애널리틱스 체크리스트 적용 중.
